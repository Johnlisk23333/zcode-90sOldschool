# zcode-90sOldschool — ZCode 桌面端外观增强插件

# 莪今兲眞旳卟葙冩代碼ㄋ

> 给 ZCode 桌面客户端加一层可随时开关、可一键还原的外观增强：主题配色、背景图、毛玻璃/果冻玻璃、
> 雨雪星光动效、字体切换、分层可读性遮罩、模型速度（TPS）与余额显示、火星文显示层等。
>
> 参考 [zcode-toolkit](https://github.com/c80361619/zcode-toolkit) 的 asar 注入思路，**独立实现并扩展**。

## 快速开始

**环境**：Windows 10/11 + Python 3.9+（补丁器只用标准库，**不需要 pip 安装任何东西**）。

1. 下载本仓库（`Code → Download ZIP` 解压，或 `git clone`）。
2. 双击 **`应用外观.cmd`**：
   - 会弹 UAC 提权（要写 `C:\Program Files\ZCode\resources\app.asar`）；
   - 若 ZCode 正在运行，脚本会等它退出后注入并自动重启；
   - 中途会问「是否安装更新后自动注入计划任务」，**直接回车 = 不装**（推荐，见下）。
3. 重启 ZCode 后，右下角出现 🎨 悬浮球，或按 **`Alt+Z`** 打开外观面板。

**一键还原**：双击 **`还原外观.cmd`**（恢复首次注入前备份的官方 `app.asar`，本地配置与素材保留）。

**看状态**：双击 **`检查状态.cmd`**（是否已注入、备份是否存在、计划任务是否在装）。

## 兼容范围

- 客户端：ZCode 桌面端（Electron）。已在 3.12.x 上验证；其它版本理论通用，但**未逐一测试**。
- 系统：Windows 10 / 11（补丁器依赖 `schtasks`、UAC 提权与文件锁行为）。
- 注入只改两处：新增引擎文件 + `index.html` 里一行 `<script defer>`；其余约 2.7 万个文件字节与偏移保持不变（补丁器自检 + 外部独立比对双重验证）。

## 客户端更新后自动注入（可选，默认关闭）

计划任务 **ZCode-Appearance-AutoHeal** 为 **SYSTEM 权限、每 5 分钟** 巡检，属于敏感操作，**默认不安装**。需要时二选一：

- 双击 `应用外观.cmd` 时在提问处输入 `Y`；
- 或命令行：`python scripts/appearance_patcher.py --install-autoheal`（先 `--apply` 过一次）。

装了之后：

- 客户端更新重置 `app.asar` 后，守护脚本等 ZCode 退出（含 4 秒稳定窗）**静默重新注入**；
- 引擎文件更新后同样在下次退出时重注入；
- 每次重注入前校验/刷新基线备份，避免用旧备份还原导致客户端降级；
- 日志：`C:\Program Files\ZCode\resources\app.asar.zcode-ap-autoheal.log`（保留最近 40 行）。

不想要：双击 **`关闭自动注入.cmd`**（`还原外观.cmd` 也会自动移除）。

## 隐私

引擎默认**零网络请求**，配置、背景图、字体全部存本机（localStorage + IndexedDB）。
唯一例外是**可选的「联动本地天气」（默认关闭）**：只向 `https://api.open-meteo.com` 发送经纬度，代码里固定 https + 主机白名单，失败静默。详见 [SECURITY.md](SECURITY.md)。

## 常见问题

**Q：注入后客户端打不开 / 白屏？**
先 `还原外观.cmd` 回滚，再确认客户端版本与操作系统，把现象提到 Issues。

**Q：客户端更新后外观没了？**
正常——更新会重置 `app.asar`。重跑 `应用外观.cmd`，或装了自动注入任务就等它巡检恢复。

**Q：提示「asar 被占用」？**
ZCode 没退干净。任务管理器结束进程后重试，脚本本身也会等待退出。

**Q：UAC 被取消？**
右键 `应用外观.cmd` →「以管理员身份运行」，或在管理员终端里执行 `python scripts/appearance_patcher.py --apply --watch --restart`。

**Q：菜单还是白底白字 / 子菜单被裁？**
v0.1.27 起已按运行时识别浮层处理。若仍复现，请附截图 + 鼠标悬停元素信息提 Issue。

**Q：不想要某个功能（比如火星文/呼吸灯）？**
面板里全部是独立开关，关掉即还原，不需要卸载。

## 实现原理与安全边界

- 补丁器（`scripts/appearance_patcher.py`，纯 Python 标准库）把外观引擎
  `scripts/zcode-90sOldschool.js` 作为新文件写进客户端 `app.asar`，并在
  `out/renderer/index.html` 的 `</head>` 前注入一行 `<script defer>`。
- **原 2.7 万个文件字节与偏移完全不变**（外部全量比对验证过）；被改写的 index.html
  与新增的引擎文件按 Electron 口径重算 SHA-256 分块 integrity。
- 已确认客户端 Electron 的 `EnableEmbeddedAsarIntegrityValidation` fuse 关闭，改 asar 不会触发校验。
- 首次注入自动备份官方包为 `app.asar.zcode-ap-bak`；`--revert` 永远还原到它。
- **零网络请求（天气联动除外）**：引擎默认不发起任何外部请求，配置/背景/字体全部存本机（localStorage + IndexedDB）；唯一例外是可选的「联动本地天气」（默认关闭）——仅向 `https://api.open-meteo.com` 发送经纬度查询实况（免费无鉴权，代码里固定 https+主机白名单校验，失败静默）。
- 客户端**自动更新会重置 app.asar**（外观失效属正常），重跑 `应用外观.cmd` 即可，个人配置不丢。

## 命令行

```bash
  python scripts/appearance_patcher.py --check                      # 查看状态（含自动注入任务）
  python scripts/appearance_patcher.py --apply --watch --restart    # 注入/更新（默认不装计划任务）
  python scripts/appearance_patcher.py --apply --with-autoheal      # 注入并安装「更新后自动注入」计划任务
  python scripts/appearance_patcher.py --install-autoheal           # 仅安装计划任务
  python scripts/appearance_patcher.py --remove-autoheal            # 仅移除计划任务
  python scripts/appearance_patcher.py --revert                     # 还原（自动移除任务）
  python scripts/appearance_patcher.py --apply --dry-run OUT.asar --asar COPY.asar --no-elevate   # 干跑测试
```

## 已知限制

- TPS 优先取客户端事件流的真实 usage 计数（v0.1.5 起）；事件流接管不到时退化为 DOM 估算（数值带 ~），此时 Token 数为折算值（CJK≈1 字/token、英文≈4 字符/token），非服务端精确计数。
- 余额「自动抓取」依赖客户端用量页的页面文本，口径变化时可能抓不到（可切手动模式）。
- 背景图开启后个别使用硬编码颜色的面板仍不透明，属客户端样式写死，非注入问题。
- 「主席书法」默认回退华文行楷/楷体；放入毛体字体文件（如方正毛体.ttf）后自动优先使用。
- 深色/浅色主题切换瞬间极小概率出现一帧旧配色（下一帧自动校正）。
